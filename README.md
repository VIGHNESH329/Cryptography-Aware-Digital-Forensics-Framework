# Digital Forensics Command Center Pro

A full-stack digital forensics platform designed for secure evidence acquisition, integrity verification, metadata analysis, AI-assisted threat detection, and automated forensic reporting.

## Features
- Secure Evidence Acquisition & Storage
- SHA-256 Hash-Based Integrity Verification
- RSA Digital Signatures for Non-Repudiation
- Role-Based Access Control (RBAC)
- Metadata Extraction from Multiple File Formats
- AI-Powered Evidence Risk Analysis
- Tamper Detection & Real-Time Monitoring
- Automated Investigative Report Generation
- Secure Evidence Vault Management

## Tech Stack
- Python
- Streamlit
- SQLite
- PyCryptodome
- Fernet Encryption
- ExifRead
- PyPDF2
- FPDF
